The main figure contains 2 common-correct and 2 any-model-error cases, selected from the previously frozen example set. Default row selection uses fixed SHA-256 ranking with class diversity, independently of confidence or heatmap appearance; an explicit --clusters override is documented in figure_protocol.json. Success/error selection categories refer to saved evaluation predictions. Cell labels show the FP32 prediction and its softmax probability; a dagger marks a difference from the saved AMP prediction. Each displayed CAM targets that model's predicted class logit. Ground-truth-target CAMs are excluded from this predicted-class comparison. Consequently a failure row may contain both correct and incorrect model predictions. Colors indicate positive attribution normalized within each map; absolute color strength cannot be compared between models. Target layers differ in spatial resolution. Non-valid maps are retained and labeled. The supplementary figure includes every example in the original selection.
